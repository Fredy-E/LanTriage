LanTriage

Experimental concept prototype — idea exploration only. This is a work-in-progress demo, not a finished or production-ready product.

Offline, bounded pcap / pcapng evidence viewer for DHCP, ARP and mDNS observations. Everything runs in this page: no server, no build step, no uploads, no telemetry. Imported data stays on this machine.

1 · Import a capture

Implemented prototype subset: classic pcap (little/big endian, micro/nanosecond timestamps) and pcapng section/interface/enhanced-packet (plus simple-packet) records with Ethernet, bounded VLAN, ARP, IPv4/UDP DHCP and mDNS. Everything else is counted as not decoded — never silently treated as healthy.

          Reports are standalone files: the HTML report is script-free and self-contained, the JSON report is plain JSON. Raw packet payloads are never included.

          LanTriage is a bounded local analysis tool for pcap/pcapng evidence. It is not a Wireshark replacement and it cannot certify network health: a capture only shows traffic that reached the capture point.

          Samples are self-authored fictional byte sequences (aa:00:… MACs, 192.0.2.x addresses), never real captures. No file is stored anywhere; imports live only in this page's memory.
